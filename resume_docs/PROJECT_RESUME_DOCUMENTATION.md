## Project Overview
**Surveillance AI** - A comprehensive video analysis platform with YouTube integration, intelligent caching, and real-time object detection capabilities.

- **Frontend**: React, TypeScript, Vite
- **AI/ML**: CLIP model for semantic video analysis
